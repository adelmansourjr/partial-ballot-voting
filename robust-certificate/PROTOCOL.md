# Integer robustness of proportional approval voting with partial reports

Fixed before running the main panels. Each observation is a binary report about whether a voter approves a proposal. An alternative clean profile may disagree with at most b observed reports in total. Unreported entries are unrestricted. All analyses use exact, lexicographically tie-broken proportional approval voting (PAV). A disagreement models a possibly incorrect or strategically changed answer. It grants the adversary no utility restrictions and does not model participation or identify any voter as strategic.

## Exact endpoint and comparators

At a shared transcript, choose the highest expected-scoring committee under independent uniform zero-conflict completions, using the original tie order. The exact rule certifies it if it wins for every feasible completion at the specified error budget. Maximise each rival's PAV score advantage separately. For each voter tabulate the best rival advantage at each exact disagreement count, then compute the exact best combination by an integer budget convolution. A rival that violates the required margin yields a reconstructible alternative full profile. Check that the reconstructed profile lies within the budget and gives the announced committee a different outcome.

At each identical transcript compare a conservative global bound, which adds one PAV point per allowed bit change to each exact zero-error rival margin, and a stronger fractional allocation bound. The latter permits a lottery over each voter's table entries subject to the total budget in expectation. Solve its Lagrange dual by checking all breakpoints with exact scaled integers and round down only after aggregation. Also report the zero-error exact certificate, which is computed under a different assumption, to quantify how many apparently certified outcomes admit a low-cost failure. The adversarial certificate has no tunable scoring or thresholds beyond the fixed error budget and tie rules.

## Panels and outcomes

Each main profile has 36 rows, six candidates and a three-seat committee. Disclose the first floor(0.90 × 216) entries of a seeded uniform permutation. All comparators use those same entries. Score every panel at conflict budgets 0, 1, 2 and 3. The primary endpoint is the paired percentage-point gain in exact certificate coverage over the fractional relaxation at b=2 on 160 fresh clustered profiles, using a paired 95% profile bootstrap and a 3-point practical threshold. Report the effect whether positive or null. Report all five historical sources separately, with equal-source averages and no population-level interval. The secondary panel is 80 independent profiles. Historical profiles overlap within a source and use masked projections of previously examined archives. Their seeded candidate and voter draws are new for this analysis. They are not independent deployments or measurements of actual fraud.

Synthetic clustered voters each get six independent standard normal utilities. A faction, drawn with probabilities .49, .31, .20, adds 2.3 to its two preferred coordinates. Independent profiles use only the standard normal utilities. Synthetic ballot lengths are 1, 2, 3, 4 with probabilities .18, .38, .32, .12. Each profile draws a random global candidate label permutation. Profile seeds begin at 4191270 (clustered) and 4192270 (independent). Mask seeds add 19000 to the profile seed. Use 24 draws per each of the five qualifying pinned Pabulib approval sources. Draw 36 ballots without replacement and six projects without replacement. Use base 4193270 plus 100 times the pinned source index and the draw number. The inherited parser's source rules exclude cumulative votes. The binary reports exposed by the procedure are truthful in these replays. The perturbations are possible alternative reports, evaluated constructively, and do not assert that the original election experienced misreporting.

Run an independent exhaustive check of all clean completions on 48 three-candidate, three-voter profiles, spanning budgets 0–3 and checking all committee gaps and both tie directions. In addition, look for a strictly separating synthetic fixture against the fractional relaxation on a separate development band of up to 20,000 six-candidate, six-voter cases, disclosure 90%, budget 2. This deliberate counterexample search is separate from measured frequency. The published JSON includes the fixture or records that none was found, all panel outcomes, and several profile-level witness summaries. The bootstrap resamples whole synthetic profiles with seed 4198860 for 4,000 draws.
