# Protocol for two-question lookahead in proportional approval voting

The previous experiment found an exact 36-to-24 answer separation on one voting profile and little average gain from adding threshold questions to a myopic selector. This experiment asks whether that result changes when the selector can plan a second question conditional on the first answer.

## Design

Use twelve voters, five candidates and two seats, with the original study's PAV scores, fixed tie order, exact completion certificate, and uniform working posterior over feasible completions of each row. Under the individual interface, ask whether a voter approves a particular candidate. Under the mixed interface, also allow yes/no questions about whether their total approvals exceed a threshold. Each informative answer costs one unit. The latent ballots are used only by the evaluator to answer queries and score outcomes.

Compare four policies using a two-by-two design. The first factor is the available question interface. The second is maximisation of expected certificate pressure at one-step or two-step horizon. The one-step policies reproduce the original certificate-pressure controls. At each real transcript, freeze the expected-score leader and up to three most threatening challengers with exactly the same weighting as those controls. For the two-step variant, score each first query by its immediate expected reduction in the resulting weighted margin plus the expected optimal second-step reduction across both possible answers. The second query can contact any voter and can differ by first answer. This objective adds across voters, so the second query is the better of a query on the updated row and the best one-step query on any other row. A fully known row has no actions. Apply the original pre-seeded query priority to ties. Execute the first query and replan after the actual answer, checking the unchanged certificate at every possible stopping point. The optimisation is exact for the frozen additive objective at two steps. It does not optimise total questions to certification or reselect the objective within the planned step.

## Outcomes and comparisons

Generate 120 previously unused clustered profiles from seeds 712100 through 712219 using the original generator. The unit of inference is one complete profile. The primary effect is the mean paired saving from the mixed interface relative to the individual interface at horizon two. Report the paired 95% percentile interval from 5,000 bootstrap replicates with seed 712901. A practically meaningful positive finding requires a mean saving of at least 5% of the two-step individual baseline and a strictly positive lower interval endpoint. Record all four mean query counts, threshold use, errors, and coverage by 30 questions. Report both same-interface lookahead effects, the original one-step interface contrast and the interaction of interface and lookahead. Use the same paired resamples for these secondary effects and do not treat their intervals as confirmatory. Test fixed-policy sensitivity by repricing the recorded transcripts at 1.5 and 2 cost units per threshold answer. These sensitivity calculations hold the policy fixed.

Use 36 separate profiles each for independent, polarised and near-consensus utility generators with seeds 712300 through 712335, 712400 through 712435 and 712500 through 712535. On the five eligible, hash-checked sources from the original public ballot archive, run 20 new projections per source using seeds 713000 plus 100 times the source index plus the projection index. Report results by source and use an equal-source average. The original recorded choices are projected counterfactually and do not measure how voters would answer the queries or their effort. Treat these projections as descriptive robustness checks.

## Audit

Before the empirical run, compare the one-step implementation with the original certificate-pressure controller on eight disjoint development profiles. Independently enumerate all feasible first and conditional second queries in small partial transcripts and verify both horizons against exact direct leaf evaluation. On every run, assert that each paid answer narrows the feasible ballot set, preserves truth and cannot widen a certified margin. Every final committee must equal the full-information, tie-broken winner. Save the protocol digest and profile-level outcomes. Rerun the frozen test by comparing its emitted JSON byte-for-byte.
